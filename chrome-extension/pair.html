Pair Chrome with OpenCore

Checking the OpenCore extension…

If this page stays here, finish loading the extension in this Chrome profile:

  1. Open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the folder opened by OpenCore's Open extension folder button. If already installed, press Reload on the OpenCore Browser Control card.
  3. Return to OpenCore and select Pair Chrome again.

You can also copy OpenCore's pairing code, open the OpenCore Browser Control extension popup, and select Connect.
