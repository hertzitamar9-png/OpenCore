Media Studio → Images and regular chat → Images now offer **2K (2048 × 2048), 4K (4096 × 4096), and 8K (8192 × 8192)** output sizes. Large exports generate at 1024 × 1024 and upscale locally with Lanczos, keeping model inference bounded. The form labels this clearly; PNG metadata records both render and export dimensions. Existing smaller sizes remain available. Managed model installations always request an actual inference test before becoming Ready.

The permanent **OpenCore Setup.exe** is unchanged: 483,328 bytes (472 KB in Windows). Keep the same file for every release; it fetches the latest complete app and its required helpers. App updates remain manual: press **Update ready** once and that same button shows **Updating…**.

This release adds word/prefix discovery and task, format, publisher, license and sorting filters to the Hugging Face browser. Public searches are anonymous. Token-backed discovery is explicit, tokens stay protected by Windows DPAPI, and removing a token returns search to public mode.

The built-in catalog now contains 1,004 pinned packages in 189 families. It includes Hi3D v1.0, Unlimited OCR 2, Qwen3.5 4B 3D Coder, and the previously listed Fibo 2.0 Dev. The 3D Coder provides the publisher's Q4_K_M and Q8_0 GGUF options. Hi3D, Unlimited OCR 2 and Fibo require compatible specialized runtimes that are not yet integrated; Fibo also requires publisher approval. The catalog retains real verified options and does not fabricate quantizations.

The LoRA selector offers installed adapters whose declared base matches the selected image model. MOSS and Qwen have isolated ComfyUI runtimes, bundled pinned loader sources, and compatible safetensors dependencies. Both completed real chat image generations with their matching LoRAs on the installed 0.3.186 public package. Standard complete Diffusers imports also prepare automatically and retain their images in chat history. Other architectures, video LoRAs, publisher access requirements, and memory limits still require compatible runtimes and hardware; catalog availability is not a universal execution guarantee.

Downloads and working inference remain separate. Supported text formats prepare their managed runtime and must pass a real generation before Ready. The newly cataloged specialized image, LoRA and Phonon-2.5 packages show their missing runtime/base-model requirements. This release does not certify that every Hub architecture runs locally.

Phonon no longer auto-installs merely because its card mounts. Verified unchanged speech dependencies are reused; explicit repair remains available. Startup verification IDs cannot revive an acknowledged Phonon success notification. Model-view caching, shared installation progress and duplicate-install protection remain in place.

**Temporary chat** uses the already running local model and real ECHO retrieval in RAM. It avoids the saved-chat and disk-archive paths, rejects cloud/gateway backends, bypasses environment proxies, and closes its memory and requests on dismissal.

**OpenCore Remote for Android** is included as OpenCore.Remote.apk. Enable remote access in PC Settings and pair with the single-use QR code. The client pins the PC certificate and uses a direct TLS connection; generation runs on the PC. Generated files can be opened on the phone where supported. Remote access defaults off, paired phones can be revoked, and the PC must remain awake with OpenCore open. OpenCore attempts automatic router setup and a saved dynamic DNS address for mobile-data access; if the network blocks it, a private VPN can provide a direct route. The DNS provider receives the PC's public IP address; chat and file content does not pass through a cloud relay. Actual phone and cellular-route acceptance testing is still pending; desktop fixtures are not phone proof.

Existing connector tabs/control fixes, consistent gray Session/GPU/VRAM/speed footer, and preservation of chats, credentials and downloaded weights continue unchanged. The distribution preserves the verified 0.2.305 native code baseline and updates its declared UI/data slots and managed helpers.
