Download **OpenCore.Setup.exe** below. This small downloader is under 2 MB and uses the OpenCore logo. When opened, it downloads and verifies the full app package, then opens OpenCore Setup. The package includes Python, pip bootstrapping, bundled Node helpers and the native inference runtime; it installs WebView2 if needed. Download progress can be paused and resumed. Model files and supported model-specific dependencies prepare inside the app.

This release includes shared installation progress and duplicate-install protection, managed pip repair, the requested model quantizations, the Hugging Face importer and optional token setting, connector tab/control fixes, removal of the duplicate generic Phonon card, and the gray Session / GPU / VRAM / speed footer.

OpenCore checks for releases without downloading them. When an update is available, choose **Update ready**, then **Download update**. Updates preserve the installation folder and reopen the app. Your chats, credentials and model downloads are separate from the installer.

The Hugging Face browser now searches matching community quantizations by default. Cards offer **Find more quantizations**, show the source repository, and group the results under the same model. Duplicate publisher copies and draft models do not count toward the distinct quantization total. When fewer than five verified choices are found, the app says so.

EdgeRock includes eight GGUF choices and an automatically prepared Windows RMA engine. Tess 4.5 includes 25 GGUF choices. Five EdgeRock quants passed real generation and streaming on Windows; Tess IQ2_XXS also passed locally through ECHO. Flint and Raon retain their managed Windows runtimes. Large downloads now use bounded parallel transfers with pause/resume, checksum verification and a disk-space reserve.

The app checks real generation before marking a variant ready. Larger variants still require enough RAM; publisher formats without a Windows adapter show their requirements. These changes do not make every architecture or every Hub format executable. The current distribution preserves the verified 0.2.305 native baseline; see `distribution/README.md` for the source recovery boundary.
