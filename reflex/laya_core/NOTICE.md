# Laya runtime code

`rl_common.py` and `rl_agent_api.py` are copied unchanged from
[convaiinnovations/laya](https://huggingface.co/convaiinnovations/laya) (Apache-2.0).
OpenCore Reflex fine-tunes the Laya decision model (ModernBERT-large encoder plus a
decision head), starting from [cklxx/laya-browser](https://huggingface.co/cklxx/laya-browser)
v10 (Apache-2.0).
