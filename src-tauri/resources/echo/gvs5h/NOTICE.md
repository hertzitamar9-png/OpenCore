It does not use the benchmark solver that overwrites solution.py, download benchmark datasets, call cloud providers, or reproduce the published benchmark result. Each role invokes the same installed local model sequentially. Rust remains responsible for tool execution, approvals and cancellation; ECHO retains exact history. This is an adapted GVS5H integration, not Claude Code or an unchanged upstream benchmark runner.
